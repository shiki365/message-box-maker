メッセージボックスメーカー

ココフォリアで発言するとルーム画面の下に出る、立ち絵つきのメッセージボックスを、OBS に好きなデザインで映すための「カスタムCSS」を作ります。ルームの盤面や駒は消えて、メッセージボックスだけが映ります。すべてブラウザの中だけで処理され、入力した内容がどこかに送られることはありません。マシュマロでいただいた要望から生まれたツールです。

デザインのひな形

ブラウザソースの大きさ

OBS のブラウザソースに入れる幅と高さです。立ち絵は箱の上にはみ出すので、高さは立ち絵のぶんも取ってください。幅が 900 より狭いと、ココフォリアが立ち絵とダイスを小さくするので、このツールでは大きさを決め直しています。

位置

箱の幅は最大の幅です。ソースが狭いときは、左右の余白を残して縮みます。

箱

本文の高さは、本文の文字の大きさで何行ぶんかです。それより長い発言は、ココフォリアが 1 文字打つたびに下へ送るので、最後の行まで読めます。
ボタンはスキップ（▶）と閉じる（×）です。「マウスを乗せたときだけ」にすると、配信には映らず、OBS の「対話」からだけ押せます。

名前

札は箱の上の縁に少し重ねて付きます。「札を上へ」で重なりを減らし、さらに上げると札と箱の間が空きます。「本文との間」は、札と本文の 1 行目のすき間です。

メッセージボックスの名前には、キャラの色の情報がありません（チャット欄と違い、ココフォリアが色を付けていません）。そのため名前の色は 1 色です。「箱の上に札を付ける」では、ダイスの結果も札の横に並びます。

ダイスの結果
成功 失敗 その他

色の分け方はココフォリアと同じです。成功は「成功」「スペシャル」を含む結果、失敗は「失敗」を含む結果（ファンブルも）、成否のないロール（2D6 など）はその他です。

ココフォリアがメッセージボックスに出すのは、ダイスの結果の最後の「＞ …」の部分だけです（CCB<=50 なら「＞ 成功」、2D6 なら「＞ 9」）。出目（23 など）はメッセージボックスに入っていないので、CSS でも出せません。目標値は本文のコマンド（CCB<=50）として出ます。
出目まで映したいときは、チャットウィンドウメーカーと組み合わせてください（下の「出目まで映したいとき」）。

本文

ふちどりは、箱の中に置いた名前とダイスの結果にもかかります。

「名前で指定（PCのフォント）」では、この PC に入れたフォントが使えます。OBS を動かす PC にも同じフォントが入っている必要があります。

変えられないところ

文字を打つ速さ（1 文字 0.08 秒、句読点と改行のあとは 0.8 秒）、次の発言までの間（打ち終わってから 1.2 秒）、どの発言を出すか（メイン・情報タブの、ページを開いたあとの発言）は、ココフォリアのプログラムが決めているので、CSS では変えられません。

立ち絵

立ち絵は箱の上に立ちます。「箱に重ねる」を増やすと、足元が箱の後ろ（または前）に沈みます。縦に長い立ち絵は「高さの上限」で縮めます。
キャラの設定で「発言時キャラクターを表示しない」にしているときや、立ち絵のないキャラ（KP など）の発言では出ません。差分は、ココフォリアで「…@笑顔」のように発言すると切り替わります。

ダイスの画像

箱の右上（立ち絵が右のときは左上）に、回りながら出ます。
ココフォリアのルーム設定で「旧ダイス演出を利用する」をオンにしたときだけ出ます。オフ（最初の設定）では 3D のダイスが盤面で転がりますが、盤面ごと消えるので OBS には映りません。シークレットダイスでは出ません。

ルーム

ココフォリアでルームを開いたときの URL を貼ります。書き出す CSS の先頭にも書き込まれます。

プロジェクト

作業内容はこのブラウザに自動で保存されます。卓ごとにデザインを変えるときは「プロジェクトを保存」で分けておくと便利です。

OBS での設定

  1. ソースを追加 →「ブラウザ」。URL にルームの URLを入れます：
    https://ccfolia.com/rooms/{ルームID}
    チャットウィンドウメーカーと違い、末尾に /chat は付けません。
  2. 幅と高さに、上に出ている ブラウザソースの大きさ を入れます。
  3. 「カスタム CSS」の中身を全部消して、コピーした CSS を貼り付けます。ルームの盤面や駒は消えて、何も映らなくなれば OK です。
  4. 「OBS で音声を制御」をオンにして、音声ミキサーでこのソースをミュートします。オフのままだと、ルームの BGM やダイスの音が PC から二重に鳴ります。
  5. ココフォリアへのログインが必要です。いったん URL を https://ccfolia.com/ にして、ソースを右クリック →「対話」でログインしてから、URL を元に戻します（1 回やれば覚えています。ほかのブラウザソースとも共通です）。

映り方

  • 出るのは、ソースを読み込んだあとのメイン・情報タブの発言です。OBS を起動した直後やソースを読み込み直した直後は、次の発言まで何も映りません。
  • 発言が続くと 1 件ずつ順番に出ます。最後の発言は消えずに残ります。
  • 消したいときは、OBS でソースを右クリック →「対話」を開き、ボックスにマウスを乗せて出てくる「閉じる」（×）を押します（「箱・配置」タブの「ボタン」が「マウスを乗せたときだけ」のとき）。自分のココフォリアの画面で閉じても、OBS のほうは閉じません（閉じたかどうかはブラウザごとに別です）。ソースのプロパティで「現在のページのキャッシュを更新」を押しても消えます。
  • ルームの設定でメッセージボックスを隠している（チャットの hide mb など）と、OBS にも出ません。
  • ほかの人あての秘話は出ません（ログインしているアカウントあての秘話は出ます）。
  • ダイスの画像を箱の上に出すには、ルーム設定の「旧ダイス演出を利用する」をオンにします。オフのときの 3D ダイスは、盤面と一緒に消えます。

出目まで映したいとき（チャットウィンドウメーカーと組み合わせる）

メッセージボックスには「＞ 成功」のような最後の部分しか出ませんが、チャット欄には (1D100<=50) ＞ 23 ＞ 成功 のように全部出ます。台詞はメッセージボックス、ダイスの結果はチャット欄から、と分けて映すのがおすすめです。

  1. チャットウィンドウメーカーで、ひな形「ダイス速報（1件を大きく）」を選びます。最新のダイスを 1 件だけ大きく出して、10 秒で消えます。色や書体は、このツールと同じ選び方で合わせられます。
  2. OBS にもう 1 つブラウザソースを追加し、URL を末尾が /chat のチャット画面（https://ccfolia.com/rooms/{ルームID}/chat）にして、チャットウィンドウメーカーの CSS を貼ります。ログインは共通なので、入り直す必要はありません。
  3. ダイスの窓を、メッセージボックスの上や横（立ち絵のない側）に置きます。

GM が 1 人で、台詞ごとに立ち絵を出したいとき（シナリオテキストメーカーと組み合わせる）

メッセージボックスに出る立ち絵は、発言したキャラクターの立ち絵です。GM が NPC や PC の台詞をまとめて送るときに、台詞ごとに立ち絵を切り替えたいなら、シナリオテキストメーカーが使えます。台本を貼って、話し手ごとに立ち絵を登録すると、ココフォリアの「シナリオテキスト」としてまとめて読み込めます。一覧から送るだけで、このツールで作ったデザインのメッセージボックスに、そのキャラの立ち絵が出ます。

うまく映らないとき

  • 何も映らない → ソースを読み込み直したあとに発言があったか、ログインしているかを確かめてください。CSS を消すとルームの画面が見えるはずです。
  • ルームに入る前の画面や、ログインの画面が映る → 手順 5 でログインしてください。
  • 立ち絵の上が切れる → ブラウザソースの高さを上げるか、「立ち絵・ダイス」タブの「高さの上限」を下げてください。

PC に入れたフォントを使うとき

  • フォント欄で「名前で指定（PCのフォント）」を選び、フォント名を入れます。Chrome / Edge では「一覧から選ぶ」で、PC に入っているフォントを見た目で選べます（初回はフォントの使用の許可を聞かれます）。
  • OBS は自分の PC のフォントで表示するので、OBS を動かす PC にも同じフォントを入れてください。入っていないと、ふつうのゴシック体になります。

このツールについて

マシュマロでいただいた「メインの吹き出しも自由にデザインしたい」という声から作りました。ダイスの結果や秘匿チャットを映すなら、姉妹ツールのチャットウィンドウメーカー、GM が 1 人でも台詞ごとに立ち絵を出せるシナリオテキストメーカーもどうぞ。「こんなツールがほしい」「ここが使いにくい」といった声も、マシュマロからお気軽にどうぞ。

ブラウザだけで動く無料ツールです。作った CSS は自由に使えます。
ココフォリアの画面の作りが変わると、表示が崩れることがあります。いずれのサービスとも関係のない非公式のツールです。
