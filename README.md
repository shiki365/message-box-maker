# メッセージボックスメーカー

ココフォリアで発言するとルーム画面の下に出る、立ち絵つきのメッセージボックスを、OBS に好きなデザインで映すための「カスタム CSS」を作るツール。ルームの盤面や駒は消えて、メッセージボックスだけが映る。プレビューで発言を送りながら確かめられる。

**公開サイト: https://shiki365.github.io/message-box-maker/**

手元で使う場合も、`index.html` をブラウザで開けば動く（サーバー不要・インストール不要）。

マシュマロでいただいた「メインの吹き出しも自由にデザイン・制作できるツールがほしい」という要望から作った。ダイスの結果や秘匿チャットを映すなら、姉妹ツールの [チャットウィンドウメーカー](https://shiki365.github.io/chat-window-maker/) を使う。ほしいツールの要望や感想は [マシュマロ](https://marshmallow-qa.com/jisg2c3imbza76d) へ。

## できること

- **ひな形 7 種** — ココフォリア風（標準）/ ノベルゲーム / 古い紙（手紙）/ SF 通信 / ホラー / RPG のメッセージ窓 / やわらかい吹き出し
- **箱・配置** — 幅、中央・左・右に寄せる、下と左右の余白、出かた（下から滑り出る / その場に出る）、背景・質感（古い紙・ざらつき・走査線・下に向かって濃く）・枠線・角丸・影・四隅のかっこ、余白、本文の高さ（行数）
- **名前** — 箱の中の見出しの行か、**箱の上に付ける札**（札の色・角丸・枠線・位置）
- **ダイスの結果** — 「🎲 ＞ 成功」を成功・失敗・その他で色分け。名前の後ろか右端、文字だけ / 枠 / 色の帯
- **本文** — フォント 40 種＋ PC に入れたフォントを名前で指定（Chrome / Edge では一覧から見た目で選べる）、行の高さ、字間、ふちどり
- **立ち絵** — 幅、高さの上限、左右、端からの位置、箱に重ねる量、箱の前か後ろか、左右反転
- **ダイスの画像** — 出す・出さない、大きさ（ルーム設定「旧ダイス演出を利用する」がオンのときだけ出る）
- **スキップ・閉じるのボタン** — 出さない / OBS の「対話」でマウスを乗せたときだけ / いつも
- プレビューはルーム画面の再現（盤面・駒・チャット欄つき）で、「CSS を当てる前」に切り替えられる。チャット・ダイス（成功 / 失敗 / 成否なし）・シークレットダイス・長文（立ち絵なし）を送って、ココフォリアと同じ文字送りで確かめられる。元に戻す / やり直す、自動保存、プロジェクトファイル

## 仕組み

メッセージボックスはルームの画面（`https://ccfolia.com/rooms/{ルームID}`）にだけある。`/chat` のチャット画面には無い。なので OBS のブラウザソースでルームの画面を開き、CSS で**メッセージボックス以外を全部消す**。

画面の作りは、ココフォリアの配布している JavaScript から読み取った（1.37.4、2026-09-25）。

```
div.MuiPaper-root[role="status"][aria-live="polite"][aria-label="メッセージ"]   外枠（MUI の Slide で下から出る）
  img                              立ち絵（あるときだけ）。箱の上に立つ
  div.MuiPaper-root                箱
    div                            ダイスの画像（旧ダイス演出のときだけ中身がある）
    div.MuiToolbar-root            見出しの行
      h6.MuiTypography-subtitle2   名前（キャラの色は付かない）
      p.MuiTypography-body2.css-xxxx  「🎲 ＞ 成功」
      div                          空き（flex-grow）
      button × 2                   スキップ・閉じる
    div                            本文の入れ物（高さ固定、1 文字ごとに一番下へスクロールされる）
      p                            本文（1 文字ずつ足される）
```

- **ルームの画面を消す** — `body { visibility: hidden }` にして、メッセージボックスとその中身だけ `visibility: visible` に戻す。`visibility` は子が上書きできるので、盤面や駒の DOM を 1 つずつ調べなくてよい。背景は `html, body, #root` を透明に
- **閉じたときに消える** — 閉じると MUI の Slide が外枠にインラインで `visibility: hidden` を付ける。表示に戻すルールは `:not([style*="visibility: hidden"])` で、それを上書きしない
- **位置** — 外枠を `position: fixed` にして、ブラウザソースの下に置く。右のチャット欄の幅に左右されない
- **名前の札** — 見出しの行ごと `position: absolute` で箱の上に出す。ダイスの結果も札の横に並ぶ
- **その場に出る** — Slide のインラインの `transform` と `transition` を `!important` で打ち消す
- **成功・失敗の色** — 結果は MUI の Typography（body2、color が primary / secondary / textSecondary）。チャット欄の結果と同じスタイルなので、クラスも同じ（成功 `css-1l6qhgm` / 失敗 `css-1j13mke` / その他 `css-ucj12`）。OBS で 3 種とも確認
- **ボタン** — 「マウスを乗せたときだけ」は `html:hover` のときだけ出す。OBS の「対話」でマウスを乗せたときだけ効く
- プレビュー（`mock.v1.js`）は、メッセージボックスの元のスタイル（Paper の背景と elevation 6 の白い重ね、本文の高さ 80px など）と動き（1 文字 80ms、句読点・改行のあと 800ms、打ち終わって 1.2 秒で次へ、最後の発言は残る、閉じる）を再現している

## CSS では変えられないこと

- 文字を打つ速さ、次の発言までの間
- どの発言を出すか（メイン・情報タブの、ページを開いたあとの発言。ほかの人あての秘話は出ない）
- キャラごとの名前の色（メッセージボックスには色の情報が無い）
- 発言ごとの動き。メッセージボックスは発言ごとに作り直されない（中身だけ変わる）ので、CSS のアニメーションは最初の 1 回しか動かない。同じ理由で「時間がたったら消す」もできない

## 増やし方

- **ひな形** — `presets.v1.js` の `DESIGNS` に 1 つ足す。`BASE_LOOK` に対する差分だけ書けばよい
- **フォント** — `presets.v1.js` の `FONTS` に足す。`weights` は Google Fonts に実在する太さだけにする

## 気をつけること

- OBS 32.2.2 と本物のテスト用ルームで確認済み（2026-09-25）: ルームの画面が消えて背景が透明になる、名前の札・立ち絵、成否の色 3 種、旧ダイス演出でのダイスの画像、シークレットダイス、3 行までの長文の文字送り
- **最後の発言は閉じるまで残る**。閉じたかどうかはブラウザごとなので、自分のココフォリアで閉じても OBS 側は閉じない。OBS の「対話」で閉じるか、ソースを読み込み直す
- OBS は CSS を変えるとページを読み込み直すので、出ていたメッセージボックスも消える
- ルームの BGM やダイスの音も鳴るので、ソースの「OBS で音声を制御」をオンにしてミュートする
- ココフォリアの画面の作りやテーマの色が変わると、表示が崩れたり成否の色分けが効かなくなったりすることがある
- Google Fonts を使うので、OBS の PC がインターネットにつながっている必要がある
